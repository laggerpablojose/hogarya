# Actividad 02 - Modelo UML de Clases

## Objetivo

Construir el modelo conceptual de clases UML del sistema HogarYA a partir del enunciado general y de los requerimientos identificados en la Actividad 01.

## Alcance

La actividad se centra en identificar:

- Entidades del dominio.
- Atributos principales.
- Relaciones entre clases.
- Cardinalidades.

No se modelan métodos, pantallas, arquitectura, base de datos ni comportamiento dinámico.

## Artefactos

- Diagrama UML de clases en formato imagen.
- Archivo fuente editable de draw.io.
- Informe interno de desarrollo del modelo.
- Documentación resumida del modelo conceptual.
