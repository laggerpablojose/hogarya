# Actores

## Actores principales

| Actor       | Descripción                                                                      |
| ----------- | -------------------------------------------------------------------------------- |
| Empleado    | Gestiona propiedades, publicaciones, contratos, facturación, pagos e incidentes. |
| Inquilino   | Participa en contratos, pagos y seguimiento de incidentes.                       |
| Propietario | Administra propiedades vinculadas a contratos de alquiler.                       |
| Interesado  | Consulta propiedades disponibles y manifiesta interés por alquilar.              |

## Actores internos

| Actor             | Descripción                                        |
| ----------------- | -------------------------------------------------- |
| Vendedor / Agente | Gestiona publicaciones y atención a interesados.   |
| Administrativo    | Gestiona contratos, facturación y pagos.           |
| Gerente           | Consulta información consolidada para supervisión. |

## Objetivo

Identificar los participantes que interactúan o se ven afectados por el sistema HogarYA.
