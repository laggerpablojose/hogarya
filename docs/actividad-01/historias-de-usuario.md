# Historias de Usuario

## Resumen

El backlog inicial del proyecto está compuesto por historias agrupadas en dos dominios funcionales:

### Gestión de propiedades y alquileres

- HU01 Registrar propiedad
- HU02 Consultar propiedades
- HU03 Modificar propiedad
- HU04 Crear publicación
- HU05 Gestionar publicación
- HU06 Consultar publicaciones
- HU07 Registrar interés o visita
- HU08 Generar contrato
- HU09 Validar superposición de contratos
- HU10 Gestionar estado de contrato
- HU11 Generar facturas
- HU12 Consultar facturas
- HU13 Registrar pagos

### Gestión de incidentes

- HU14 Registrar incidente
- HU15 Actualizar estado de incidente
- HU16 Consultar incidentes
- HU17 Registrar informe de resolución
- HU18 Consultar incidentes del propietario
- HU19 Consultar incidentes del inquilino

### Supervisión y continuidad operativa

- HU20 Tablero de control gerencial
- HU21 Consulta integral de una gestión
