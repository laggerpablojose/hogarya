# HogarYA

Trabajo Práctico Integrador

Materia: Desarrollo de Sistemas de Información (DESI)
Carrera: Tecnicatura universitaria en Tecnología de la Información
Universidad: UTN Facultad Regional Santa Fe

## Descripción

HogarYA es un sistema para la gestión de alquileres e incidentes de mantenimiento de una inmobiliara.

El proyecto se desarrolla de manera incremental a través de las distintas actividades del Trabajo Práctico Integrador de la materia DESI.

- docs/: documentación del proyecto
- source/: implementación y artefactos técnicos
- decisiones/: registro de decisiones de diseño (ADR)
